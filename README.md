 # CSV Writer

Пишу приложение, которое должно генерировать отчеты в разных форматах, хочется генерировать какой-нибудь отчёт в CSV, но проблема в том, что у нас нет такого инструмента. Поэтому мы решаем, что нам нужна библиотека для генерации CSV файлов.
Реализация построена с помощью Reflection и аннотаций.

Папка model содержит классы, которые нужно сохранять в CSV. Классы можно изменять и добавлять новые.

**Описание:**<br>
 Написана реализация Writable, которая будет сохранять объекты в CSV формате в файл<br>
 Написаны unit тесты<br>
 Написана JavaDoc<br>
 Для генерации тестовых данных использован Datafaker<br>
 В main есть несколько примеров сохранения данных в файл
